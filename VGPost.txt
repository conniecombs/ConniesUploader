[size=5][b]🚀 What's New in v3.0.0[/b][/size]

[list]
[*][b]Major architecture update:[/b] Host-specific Go service modules have been replaced by Python-owned plugin workflows and a generic Go HTTP transport runner.
[*][b]New sidecar actions:[/b] Generic upload, raw HTTP request, and deferred batch-result resolution make host integrations easier to debug and extend.
[*][b]Scheduled ViperGirls posting:[/b] Scheduled posts now use the same Python form-aware flow as immediate posts.
[*][b]Activity terminal:[/b] Use [b]View > Activity Terminal[/b] to tail the persisted upload activity log during longer sessions.
[*][b]Cleaner project layout:[/b] Python runtime code now lives under [b]frontend/[/b], Go sidecar code under [b]backend/[/b], and packaging assets under [b]packaging/[/b].
[*][b]Settings migration:[/b] App settings are preserved and moved out of the checkout to [b]~/.conniesuploader/user_settings.json[/b].
[*][b]Turbo reliability fix:[/b] Deferred Turbo result matching now handles result pages that refer to sanitized filenames.
[/list]

[size=5][b]⚙️ How to Use[/b][/size]

[b]1. First-Time Setup[/b]
Go to [b]Tools > Set Credentials[/b] and enter your API keys and login credentials.
[i]Note: imx.to requires an API key for gallery creation. ViperGirls posting requires saved forum credentials and posting targets.[/i]

[b]2. Basic Upload Workflow[/b]
[list]
[*]Click [b]File > Add Files[/b], [b]File > Add Folder[/b], or drag and drop files/folders into the queue.
[*]Choose your image host from the service dropdown.
[*]Select your output template, such as BBCode, HTML, Markdown, or a ViperGirls posting template.
[*]Adjust gallery, thumbnail, cover, worker, thread, scheduling, and output settings as needed.
[*]Review Import Checks and Upload Checks before starting.
[*]Click [b]Start Upload[/b].
[*]Once finished, review the completion summary and copy/open the generated output.
[/list]

[b]3. Gallery Management[/b]
Access [b]Tools > Manage Galleries[/b] to refresh host galleries, search and sort results, pin favorites, copy IDs/URLs, open galleries, create supported galleries, assign galleries to selected batches, or use cached galleries when a live refresh is unavailable.

[b]4. Template Editing[/b]
Use [b]Tools > Template Editor[/b] to customize BBCode, Markdown, HTML, ViperGirls posting, or your own output formats with image, gallery, cover, batch, service, date, and thread placeholders.

[b]5. ViperGirls Posting[/b]
Use the ViperGirls tools to save posting targets with thread URLs, fetched thread titles, tags, and notes. Select a target per batch, preview the generated post, optionally confirm before posting, schedule posts when needed, and review posting history afterward.
